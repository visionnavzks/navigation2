Smoother Weights

Constrained Smoother

Constrained Smoother uses the existing C++ Ceres objective with curvature, cusp, and ESDF obstacle terms.

These sliders show raw weights. The backend converts them to sqrt-weight terms before passing them to the solver; Constrained Smoother uses smooth_weight plus geometric curvature weights, while Kinematic Smoother uses model_weight plus its own kinematic curvature weights.

Raw weight for the geometric three-point smoothness residual used by Constrained Smoother. Higher values suppress zig-zag changes between adjacent segments, but they do not enforce a bicycle-model transition.

Raw weight for the kinematic state-transition consistency residuals. Higher values keep each state transition closer to the predicted bicycle-model motion.

Scales the ESDF-based obstacle penalty used by the smoother. Higher values push the path harder away from obstacles.

Overrides the nominal obstacle weight around cusp neighborhoods so direction-switch regions can be pushed harder away from obstacles.

Sets the full arc-length span over which cusp obstacle weighting ramps up before and after a direction switch.

Keeps the optimized solution closer to the A* reference when you do not want large detours.

Adds a per-point x/y box bound around each reference point. Leave it disabled to preserve the current unconstrained behavior.

Discourages high-curvature turns, especially around obstacle corners.

Applies a four-point D3 finite-difference penalty. Raise it to suppress sudden curvature changes without replacing the max-curvature constraint.

Penalizes the explicit kappa state used by the kinematic smoother. Higher values bias the optimizer toward lower average steering curvature, not just fewer max-curvature violations.

Penalizes changes in the explicit kappa state between transitions. This is different from the geometric smoother's four-point D3 proxy.

Minimum turning radius: 0.40 m

Caps the turning curvature. Lower values enforce a larger minimum turning radius.

Planner

A*

Scales how strongly A* detours away from low-clearance cells under the shared quadratic hinge loss. This affects the planner only, not the smoother obstacle weight.

Shared obstacle surface clearance margin used by the C++ A* planner and constrained smoother. Once the checkpoint-to-obstacle surface distance exceeds this value, the ESDF hinge penalty becomes zero. The total checkpoint-center no-penalty clearance is this value plus the robot check radius.
